## 🎯 系統架構

Bombus 人才管理系統涵蓋 7 大模組：

- **L0** - 系統核心與儀表層
- **L1** - 員工管理模組
- **L2** - 職能管理模組
- **L3** - 教育訓練管理模組
- **L4** - 績效管理模組
- **L5** - 專案管理模組
- **L6** - 價值引擎模組

---

## 🔄 模組關聯

- **L0 → L1-L6**: 提供統一的權限控制與資料整合平台
- **L1 → L2**: 員工職能資料作為職能評估的基礎
- **L2 → L3**: 職能落差分析結果驅動培訓計畫制定
- **L3 → L4**: 培訓成效資料自動更新員工職能與績效評估
- **L3 → L6**: 培訓資料供應價值引擎進行成果分析與影響力評估
- **L4 ↔ L5**: 雙向整合 - 績效資料與專案績效資料互相回饋
- **L5 → L6**: 專案成果與資料供應價值引擎進行影響力評估
- **L6 → L0**: 影響力評估結果回饋至企業管理儀表板
